# Denah Lab Biologi

Denah laboratorium biologi 3D interaktif (Three.js) dalam satu file HTML.
Letak perabot yang diatur disimpan otomatis di browser (localStorage).

## Menjalankan
Buka `index.html` di browser (butuh internet untuk memuat Three.js dan font dari CDN),
atau lihat lewat GitHub Pages.

## Deploy ke GitHub Pages
Settings → Pages → Source: branch `main`, folder `/ (root)`.
